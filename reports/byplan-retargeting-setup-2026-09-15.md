## 2. Условия ретаргетинга в Директе (Библиотека → Ретаргетинг и аудитории → Добавить)
1. **«Горячие»** — набор правил: *выполнено хотя бы одно* → сегмент RT-2. Срок: 30 дней. + правило *не выполнено ни одного* → сегмент RT-3.
2. **«Тёплые»** — *хотя бы одно* → RT-1; *ни одного* → RT-2, RT-3. Срок 30 дней.
3. **«Просто зашли»** — *хотя бы одно* → RT-4; *ни одного* → RT-1, RT-2, RT-3. Срок 14 дней (дальше интерес остывает).
4. **«Клиенты»** — *хотя бы одно* → RT-3. Только для исключения.

## 3. Кампания ретаргетинга (РСЯ, отдельная от поисковой)
- Тип: Текстово-графическая, показы только в сетях. Гео = Россия. Дневной бюджет 300–500 ₽ для старта — аудитория маленькая, больше не открутится.
- Группа A «Горячие» (условие 1), ставка ×1.5 к базовой. Текст: `Вы оставили контакт на byplan.ru — ответим сегодня. Планировка за 3 дня: 2 концепции + финал + PDF.` Быстрая ссылка → Telegram (t.me/byplandesign), WhatsApp.
- Группа B «Тёплые» (условие 2). Текст: `Анкета не дописана — не страшно. Напишите нам в Telegram, подскажем что нужно, остальное заполним вместе.`
- Группа C «Просто зашли» (условие 3). Текст: `У вас там планировка ждёт :) 2 концепции за 3 дня, 500 ₽/м². Промокод RETURN — скидка 10% до конца месяца.` (промокод — поле уже есть в анкете; размер скидки — решение Сена.)
- Ссылки с UTM: `?utm_source=yandex&utm_medium=cpc&utm_campaign=rt_{hot|warm|visitors}&utm_content={ad_id}` — по utm_campaign потом видно, какой слой возвращается.
- Креативы: картинка «было/стало» из кейсов (уже на сайте), 1080×607 и 450×450.

- Остальное — по `reports/byplan-direct-keyword-pack-2026-09-15.md` (фразы, минус-слова, гео).

## 5. Что ждать / ограничения
- Ретаргетинг по сегментам Метрики работает без порога в 100 пользователей, но при аудитории <100 показов будет мало и они дорогие — это нормально для первого месяца. Яндекс Аудитории (загрузка контактов, look-alike) требуют ≥100 записей — пока рано.
- «Полезное действие» = сегмент RT-2; «просто визит» = RT-4 минус остальные. Через неделю проверить размеры сегментов: Метрика → Отчёты → любой отчёт → «Сегмент» → выбрать RT-*.
- Проверка, что всё сработало: в Директе в статистике кампании появится разрез «Условие ретаргетинга»; в Метрике визиты с utm_campaign=rt_* .
